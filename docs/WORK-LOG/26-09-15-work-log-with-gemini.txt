작업 스케줄러에서 "무기한(Indefinitely)" 반복을 설정하기 위한 해결 방안은 크게 두 가지입니다.

2. 현실적인 최대치 할당 (우회): 
   -RepetitionDuration (New-TimeSpan -Days 3650)처럼 약 10년 정도의 허용 가능한 값을 지정하는 방식입니다.

   - 최고 권한(Highest) + S4U 로그온 유형 -> 세션 0 에서 실행되므로
     콘솔 창이 전혀 뜨지 않는다. (-WindowStyle Hidden 은 창이 깜빡일 수 있음)
   - -Mode BackupNow (상주 감시가 아니라 1회 실행). 매 5분 반복이 감시를 대신한다.
     상주 프로세스가 없으므로 죽어도 다음 주기에 스스로 복구된다.

 [트리거]
   - 컴퓨터 시작 시
   - 로그온 시
   - 워크스테이션 잠금 해제 시
   - 위 각각에 대해 5분 간격 무기한 반복

   해제:     Unregister-ScheduledTask -TaskName 'AutoDriveBackup' -Confirm:$false

현재 스크립트에 두 가지 치명적인 문제가 있습니다.

1. 과거 코드 중복 방치: 코드를 확인해보면 80~108줄에 새로 작성한 트리거 로직을 붙여넣으셨지만, 111줄부터 137줄 사이에 과거 코드(New-InfiniteRepetition 등)가 지워지지 않고 그대로 남아 있습니다. 이 상태로는 변수가 덮어씌워지거나 존재하지 않는 함수를 호출해 무조건 실패합니다.
2. CIM 속성 주입 거부 (Interval 에러): PowerShell 5.1에서는 New-CimInstance -ClientOnly로 생성한 껍데기 객체에 "PT5M" 같은 문자열 형태의 Interval 값을 직접 주입하는 것을 타입 불일치로 거부합니다.

해결 방안 및 구현 단계:

CIM 객체를 억지로 조립하는 대신, New-ScheduledTaskTrigger -Once를 이용해 가짜 트리거를 하나 생성하되 -RepetitionDuration 파라미터를 아예 생략하는 방식을 씁니다. 파라미터를 생략하면 작업 스케줄러가 이를 '무기한'으로 자동 인식하며, 여기서 안전하게 생성된 .Repetition 객체만 빼내서 나머지 실제 트리거들에 일괄 적용하면 됩니다.
